# My Personal website

A project I have wanted to work on for a long time and used phantom as an excuse


## heres how to run the project :)
1. Clone the source code to your device
```sh
git clone https://github.com/vivithequeen/horizons-guides.git
```

2. Install the project's dependencies
```sh
npm install
```

3. Start the development server on `localhost:5173`
```sh
npm run dev
```

4. Build the site to `/dist`
```sh
npm run build
```
enjoy!
